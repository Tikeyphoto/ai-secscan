✨ Возможности

Больше, чем просто сканер

  • 5 языков: Python, JavaScript, TypeScript, PHP, Java.
  • Secret Scanner: находит забытые ключи AWS, токены Telegram, пароли в конфигах.
  • SCA (анализ зависимостей): проверяет requirements.txt на известные CVE.
  • IaC Scanning: ищет уязвимости в Dockerfile (root-пользователь, latest-тег).
  • Экспорт: PDF, JSON и SARIF (для Jira, GitHub Security и CI/CD).
